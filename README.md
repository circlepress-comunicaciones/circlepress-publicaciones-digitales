# Circle Press · Publicaciones digitales

Biblioteca de publicaciones científicas con EHA 2026 y FIMS 2026, resúmenes interactivos y artículos completos.

## Publicación

Netlify publica la carpeta `dist` de la rama `main`, sin instalación ni comando de compilación. Los cambios en GitHub se publican automáticamente cuando la integración está conectada.

- Portada: `dist/index.html`
- EHA 2026: `dist/eha-2026/index.html`
- FIMS 2026: `dist/fims-2026/index.html`

Cada publicación incluye un botón “Todas las publicaciones” para regresar al listado.

## Agregar publicaciones

Crear una carpeta nueva dentro de `dist`, con todos sus recursos, y agregar una tarjeta en la portada. Conservar los enlaces relativos y revisar la navegación antes de publicar.
